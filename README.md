## Features

### Core Functions

* Command-based navigation across the entire platform
* Command-driven authentication (register, login, logout)
* Create posts and comments using commands
* Follow and unfollow users instantly

### Users & Profiles

* User registration and secure JWT authentication
* View and edit user profiles
* Search and discover users
* View followers and following lists

### Social & Content

* Create and view posts
* Comment on posts
* Browse all posts or posts by a specific user

### Interface

* Terminal-style command interface
* Dark cyber-themed UI
* Responsive design for all devices
